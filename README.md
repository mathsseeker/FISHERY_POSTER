# FISHERY_POSTER — Iceland Cod Bioeconomic Model

A dynamic optimization of the Icelandic cod fishery that solves for an
optimal Harvest Control Rule (HCR) by Value Function Iteration (VFI),
using ICES 2025 stock-assessment data as input.

Built as a poster project for the Optimization course (IE, Year 2, Q2).

## What it does

1. **Build the state space.** `params.py` holds biology (weight-at-age,
   mortality, catchability) and economics (prices, costs). `profit.py`
   builds the biomass grid `B_grid` and price grid `P_grid`.
2. **Compute the age-structured population.** `population.py` derives
   the steady-state age distribution `x(B)`, recruitment, and
   spawning stock biomass (SSB).
3. **Solve for the optimal policy.** `vfi.py` runs Value Function
   Iteration over `(B, P)` to produce the optimal value function
   `V*(B, P)` and the optimal harvest policy `H*(B, P)`, saved to
   `V_star.npy` / `H_star.npy`.
4. **Fit a Harvest Control Rule.** `hcr.py` fits a 3-piece piecewise
   linear HCR to each price column:

   ```
   H = 0                        if B ≤ B_zero
   H = slope · (B − B_zero)      if B_zero < B < B_zero + H_max/slope
   H = H_max                    if B ≥ B_zero + H_max/slope
   ```

   The result is rendered to `hcr_plot.png`.

`run_all.py` orchestrates the full pipeline end-to-end.

## Repository layout

```
.
├── run_all.py                        End-to-end pipeline
│
├── params.py                         Biology + economics parameters
├── population.py                     Age-structured dynamics, SSB, recruitment
├── price.py                          Price-vs-landings function
├── profit.py                         Per-period profit + grids
├── vfi.py                            Value Function Iteration solver
├── hcr.py                            3-piece HCR fit + plot
├── iceland_cod_data_1.py             Build Iceland cod stock dataset
├── verify_bug.py / verify_fix.py     Scripts documenting one solved bug
│
├── data/                             Input data
│   ├── iceland_cod_model_data.csv       Historical time-series
│   └── iceland_cod_reference_points.csv ICES reference points (B_lim, B_MSY, …)
│
├── results/                          Computed outputs (regenerated by run_all.py)
│   ├── B_grid.npy / P_grid.npy          Discretised biomass + price grids
│   └── V_star.npy / H_star.npy          Optimal value function + harvest policy
│
├── figures/                          Plots (regenerated)
│   ├── hcr_plot.png                     Final HCR plot
│   └── profit_check.png                 Profit-curve sanity check
│
├── docs/
│   └── UNIT_ANALYSIS.md                 Known-issue note on kg vs tonnes
│
├── .gitignore
└── README.md
```

## Running

```bash
python run_all.py
```

Dependencies: `numpy`, `pandas`, `matplotlib`, `scipy`.

## Known issues

See [`docs/UNIT_ANALYSIS.md`](docs/UNIT_ANALYSIS.md): the current code mixes
kilograms (weight-at-age) and tonnes (biomass / harvest) in several
places, which needs reconciling before the economic magnitudes can be
trusted.
